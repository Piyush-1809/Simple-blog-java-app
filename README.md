## Simple Blog Application

The Simple Blog Application is a basic Java Swing program that allows users to create and read blog posts through an easy-to-use graphical interface. Users can add new posts, browse existing posts, and exit the application whenever they wish.

### Features

* Create blog posts by entering a title and content.
* View a list of all existing blog post titles.
* Select a title to read the full content of the blog post.

### How to Use

1. Run the Java program to launch the Simple Blog Application.

2. **Main Menu Options:**

   * Click **"Create a New Blog Post"** to add a new post. You will be asked to provide a title and the content for the post.
   * Click **"View All Blog Posts"** to see a list of all available blog titles. Selecting a title will display the full blog content.
   * Click **"Exit"** to close the application.

3. **Creating a Blog Post:**

   * Choose **"Create a New Blog Post"** from the main menu.
   * Enter the blog title and content, then click **"Submit"** to save the post.

4. **Viewing Blog Posts:**

   * Select **"View All Blog Posts"** from the main menu.
   * A list of blog titles will appear.
   * Click on any title to open and read the complete blog post.
